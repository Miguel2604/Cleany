# Surface: Cleany app (menu bar popover, main window, widget)

Mode: Operate. Build path: code-led (Operate surface).

## Direction contract

THESIS: The Mac's drain is a creek at night, and idle leftovers are what the raccoon washes out of it. Refuses the category default: a gray popover with a usage ring over a grouped list.

OWN-WORLD: Dusk creek. Ground is deep blue-green water (#0B2226 dark, #DCEBE6 light) seen through Liquid Glass, which reads as the water surface. Moonlight (#EAF3EE) for text on dark, reed green tint for actions, lantern amber for "draining", one coral only for Stop anyway. SF Pro for UI, SF Rounded numerals for the waterline value, SF Symbols for icons. One drawn waterline, 1pt, always labeled.

STORY: The developer glances at the menu bar raccoon, opens the popover, reads how muddy the water is (CPU, drain state) and which category clouds it, ticks the idle items, cleans them, watches the water clear, can undo.

FIRST VIEWPORT: 360pt popover. Top: raccoon at the water's edge (56pt) beside one status sentence. Below: the creek band, a glass strip where each category segment's width is its exact CPU share, with the waterline value at its left. Then item rows with fixed columns: name plate, one-line note, state, "?". Bottom: one tinted glass primary button "Clean up N idle".

FORM: Night creek, #1 on my ordered list. seed:9b5e6bd264dba2dd. Kept raises: columns never move, only values; each item has a fixed name plate + note; nothing labeled twice; one visible grid; size is the exact value. Signature interaction: after a cleanup a ripple crosses the creek band, segments reflow narrower, the raccoon washes its paws (Reduce Motion: crossfade).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
